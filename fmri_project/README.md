# MEG Project: Event-Related Responses to Auditory and Visual Stimuli

This project was conducted by Shirley Xue, Lingwei Cao, and Eva Yi Xie as part of the NEU502B Final MEG Project.

This repository contains the code and analysis scripts for our MEG study examining event-related field (ERF) responses to auditory, visual, and audiovisual word stimuli. The analysis includes preprocessing, ERF visualization, and cluster-based permutation testing using MNE-Python. Results characterize the spatiotemporal dynamics of unisensory and multisensory processing.
