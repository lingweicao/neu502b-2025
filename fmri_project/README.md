# From Seeing to Imagining: fMRI Investigation on Visual Perception, Recall, and Imagery

This project was conducted by Shirley Xue, Lingwei Cao, and Eva Yi Xie as part of the NEU502B Final fMRI Project.

This repository contains the code and figures for our fMRI study as participants view, recall, and imagine objects from two categories. The analysis includes preprocessing, GLM, MVPA, and RSA.
